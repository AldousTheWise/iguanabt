# 🦎 IguanaBT

IguanaBT es un sitio web estático desarrollado como parte de un reto de maquetación. Presenta un diseño atractivo inspirado en una página de presentación empresarial.

## 🚀 Tecnologías Utilizadas

- HTML5  
- CSS3  
- Flexbox y Grid  
- Google Fonts  
- Imágenes optimizadas  

## 📂 Estructura del Proyecto

```bash
iguanabt/
│── index.html       # Página principal
│── styles.css       # Estilos generales
│── images/          # Carpeta con imágenes del sitio
│── README.md        # Documentación del proyecto
```

## 🛠️ Instalación y Uso
1. Clona el repositorio:
```sh
git clone https://github.com/AldousTheWise/iguanabt.git
```
2. Copiar en tu editor de texto.
3. Editar.
4. Abre el archivo index.html en tu navegador.
